# 🔒 Instructor-Only Materials

**Students:** this folder is for instructors. The file below is locked with a password.

**Instructors:** `instructor-materials.7z` contains:

| Folder | Contents |
|---|---|
| `quizzes/` | 30 quizzes (Quiz 00 to Quiz 29), one per lesson, as Word files |
| `answer-keys/` | The answer key for every quiz, with scoring notes and sample solutions |
| `quiz-sources/` | The same quizzes and keys as Markdown files, for editing |
| `code/` | The finished, tested program for every lesson (`Lesson01` to `Lesson29`) |

## How to Open It

1. Install the free program **7-Zip**: https://www.7-zip.org
2. Download `instructor-materials.7z` from this folder (click the file, then click the **Download** button).
3. Right-click the downloaded file → **7-Zip** → **Extract Here**.
4. Type the password, and click **OK**.

The password is not written anywhere in this repository. Ask the course owner for it, and do not share it with students.

> The Windows built-in "Extract All" cannot open password-protected 7z files. Use 7-Zip (or WinRAR).

## If You Change the Materials

Pack the folder again with the **same password**: right-click the `instructor-materials` folder → **7-Zip** → **Add to archive...** → set **Archive format** to **7z**, type the password under **Encryption**, tick **Encrypt file names**, and click **OK**. Then replace the file in this folder.

**Never** commit the extracted (unlocked) folder to the repository.

See the [Instructor Guide](../INSTRUCTOR-GUIDE.md) for how the quizzes work.
